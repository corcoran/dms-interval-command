# Changelog

## 0.10.1

- The delete button in the widget list can now be reached with Tab and activated with Space or Enter.
- Settings icons use the theme's icon size.
- Fix the plugin id in the README's reload command.

## 0.10.0

- Honor the bar's "Maximize Widget Text" toggle so widget output scales with the rest of the bar.
- Add a per-widget "Use Tabular Numbers" option (on by default) that applies the OpenType `tnum` feature to numeric output, eliminating digit jitter on changing values.
